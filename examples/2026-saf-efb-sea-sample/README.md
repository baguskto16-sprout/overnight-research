## What's in this folder

This is a small-scope sample showing what a smoke-test-sized run output looks like.

**Topic:** Sustainable Aviation Fuel (SAF) production from Empty Fruit Bunches (EFB) palm oil waste, focused on Indonesia.

**Why this topic:** adjacent to Cremer biomass engagement, has rich public data sources (IEA, IRENA, Indonesian Ministry of Energy, ICAO), realistic for SEA strategic interest (Singapore SAF mandates, Indonesia palm waste utilization).

**Files:**

## How to use this example

1. **Read the format.** See how IMI reference structure (numbered footnotes, multi-component costs, declarative root causes, `[ASSUMED-N]` tags, source priority) shows up in actual output.

2. **Compare to your run output.** After your smoke test or full overnight run, open these alongside your output and check structural fidelity.

3. **Sanity check yourself.** If your output is significantly thinner / less cited / less disciplined than this example, the skill may need attention.

## What this is NOT

- Actual field-validated research. The `[ASSUMED-N]` tags here represent real questions but specific values (cost figures, market sizes) are illustrative only.
- A complete run. A real run has 4-7 actors and 8-15 pain points; this sample has 2 actors and 3 pain points to keep it readable.
- Authoritative on SAF/EFB. Do not cite.
